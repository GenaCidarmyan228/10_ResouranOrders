# 10_ResoutanOrders
Ver 1.0 
Данная ИС содержит форму авторизации с ролями Администратор и Пользователь, где после трех неудачных попыток входа пользователь блокируется и не может войти, для дальнейшего входа ему нужно обратиться к администратору за разблокировкой.
Администратор может добавлять новых пользователей, разблокировать их и удалять.
ИС реализовано для предприятия по производству продукции заказчикам.
